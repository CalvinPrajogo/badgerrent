# UW Madison Housing Companies Research

## MPM
- **Website:** [Madison Property Management](https://www.madisonproperty.com/)
- **Listing Style:** Large list with rows/columns structure
- **Data Fields:**
  - Address
  - Location
  - City
  - Type
  - Beds
  - Baths
  - Sq Ft
  - Pets
  - Lease
  - Avail
  - Rent
  - Parking

## Tallard
- **Website:** [Tallard Apartments](https://www.tallardapartments.com/)
- **Listing Style:** Portfolio page with individual property pages, pricing data in AppFolio iframes
- **Data Fields:**
  - Name (Property name with bedroom count)
  - Address
  - URL (Individual property page)
  - Price (Monthly rent from iframe)
  - Price Raw (Original price text)
  - Bedrooms
  - Status (Availability status)
  - Features (Property amenities/features list)
  - Description (Detailed property description)
  - Images (Multiple property photos and floor plans)
  - Page Title
  - Company ("Tallard Apartments")
  - Location ("Madison, WI")
  - Scraped At (Timestamp)
  - **Iframe Data** (from AppFolio system):
    - Rent from Iframe
    - Bedrooms from Iframe
    - Square Feet from Iframe
    - Availability Status
  - **Additional Structured Data**:
    - Utilities Included
    - Appliances
    - Parking Available
    - Laundry Available
    - Pets Allowed
