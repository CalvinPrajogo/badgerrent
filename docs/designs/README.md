# Design Assets

This folder contains design mockups and assets from Figma.

## Organization

### Mockups
Place page mockups here organized by page:
- `home-page.png`
- `search-page.png`
- `property-detail-page.png`
- `mobile-home-page.png` (if you have mobile designs)

### Design System Assets
If you get design system assets (colors, fonts, components):
- `color-palette.png`
- `typography.png`
- `component-library.png`

## Usage

1. **Reference during development**: Use these to understand layout and styling
2. **Component planning**: Break down designs into reusable components
3. **Design consistency**: Ensure implementation matches designs

## Best Practices

- Name files descriptively
- Include both desktop and mobile versions if available
- Update this folder when designs change
- Add notes about design decisions in comments or separate `.md` files
